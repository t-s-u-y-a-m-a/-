# タスク分担表(複数AI並行作業用)

複数のAIアシスタントに同時並行で作業を依頼する際の分担案です。
**ファイルの競合(コンフリクト)を避けるため、各タスクは触るファイル・フォルダを明確に分けています。**
同じファイルを複数タスクが同時に編集すると、あとでマージする人が大変になるので、
新しく別のAIに依頼するときは「担当タスク」と「触ってよいファイル範囲」をそのまま伝えてください。

作業前に必ず現状のブランチ(`claude/ten-baby-care-game-v1-0zhsbv` / PR #1)を pull してから始めてください。

---

## グループA: 企画書のみ(コード変更なし・完全に並行できる)

新規ファイルを作るだけなので、他のタスクと衝突しません。同時に何人が着手してもOKです。

| No | タスク | 成果物 | 参考 |
|---|---|---|---|
| A1 | 『大きなかぶ』のゲーム企画書 | `docs/stories/big-turnip.md` | `docs/stories/three-bears-punipuni.md` を書式の参考に |
| A2 | 『ももたろう』のゲーム企画書 | `docs/stories/momotaro.md` | 同上 |
| A3 | 『三びきのこぶた』のゲーム企画書 | `docs/stories/three-little-pigs.md` | 同上 |
| A4 | 最終章の企画書 | `docs/stories/final-chapter.md` | 5つの物語をクリアした後の締めくくり。世界観・演出方針のみ、実装詳細は不要 |
| A5 | 絵本システム全体の企画書 | `docs/story-book-system.md` | 各物語をどう選び、どう読み進め、クリア後どうなるか。個別ゲームの中身はA1〜A4に任せ、ここでは「箱」の仕様のみ |
| A6 | 物語の世界(世界マップ)の企画書 | `docs/world-map.md` | 家画面の「物語の世界」ボタンから何が見えるか。実装(コード)はまだ行わない |

> 各企画書は「てんのお世話ゲーム」の基本理念(攻略ではなく理解する体験)を踏まえること。
> 既存の `index.html` / `script.js` / `style.css` (ルート) や `stories/three-bears/` の中身には触れないこと。

---

## グループB: 実装タスク(担当ファイルを分離)

| No | タスク | 触ってよい範囲 | 触ってはいけない範囲 |
|---|---|---|---|
| B1 | 『三びきのくま』ゲームの磨き込み(スマホ実機相当の挙動確認、触れる場所の追加〈手・足・おなか〉の仕上げ、演出の調整) | `stories/three-bears/**` のみ | ルート直下の `index.html` / `script.js` / `style.css`、`docs/**` |
| B2 | 「てんのお世話」プロトタイプのQA(完成条件チェックリストの手動確認、PC/スマホ表示崩れの修正) | ルート直下の `index.html` / `script.js` / `style.css` のみ(バグ修正レベルの小さな変更に限定) | `stories/**`、`docs/**`、お世話システムの仕様そのものの変更 |

> B1とB2は別ファイルなので同時進行OK。ただし**B2はバグ修正のみ**とし、企画変更を伴う修正はしない(企画変更が必要そうなら一旦報告してもらう)。

---

## グループC: 一人(または順番)でやるべきもの(競合しやすい/判断が要る)

| No | タスク | 理由 |
|---|---|---|
| C1 | 家画面から各物語・絵本システムへの導線をつなぐ実装 | `index.html` のホーム画面まわりを触るため、B2と競合しやすい。B2が落ち着いてから着手 |
| C2 | GitHub Pagesの公開設定、リポジトリのpublic化 | GitHubのリポジトリ設定変更で、AIではなく人(あなた)が行う操作 |
| C3 | 絵文字ベースの表示を実イラストに差し替えるかどうかの最終判断 | デザイン方針の意思決定なので、複数の企画書(A1〜A6)が出揃ってから、あなたが判断 |

---

## 進め方の推奨

1. まずグループAの6件を、空いているAIに1〜2件ずつ割り振って並行実行(完全に独立)。
2. 並行してB1・B2も別のAIに割り振り可能(こちらも独立)。
3. グループAが出揃ったら、内容を見てC1〜C3の要否・優先順位をあなたが判断。
4. 各タスクが終わるたびに、同じブランチ(`claude/ten-baby-care-game-v1-0zhsbv`)にpushしてもらう。ただし直前に必ず pull して最新化してから push すること(コンフリクト防止)。
