# 他AIへの引継ぎプロンプト集

`docs/TASKS.md` の各タスクを、このリポジトリにアクセスできない(無料版などの)AIに依頼するための、
そのままコピペして使えるプロンプトです。各プロンプトは単体で完結するように、必要な背景情報を埋め込んであります。

**使い方**
1. 該当タスクのプロンプトをそのままコピーして、別のAIに渡す
2. 出力された内容を確認し、問題なければあなた自身(またはこのセッション)がリポジトリの指定パスにファイルとして保存する
3. 保存したら `claude/ten-baby-care-game-v1-0zhsbv` ブランチにコミット・push する(このセッションに「これを保存してpushして」と頼んでもらってもOK)

---

## 共通の前提(全プロンプトに含まれています)

- プロジェクト名：「てんのお世話ゲーム」プロトタイプ
- 基本理念：「攻略するゲームではなく、理解するゲーム」。プレイヤーに正解を当てさせるのではなく、
  見る→聞く→考える→行動する→反応を見る→少し理解する、という体験を作ること
- 赤ちゃん「てん」：生後2か月の男の子、優しい・可愛い・清潔感・絵本・家族という雰囲気
- 出力は日本語のMarkdown企画書、またはコードそのもの(タスクにより異なる)

```
あなたは、ブラウザで動く赤ちゃんのお世話ゲーム「てんのお世話ゲーム」プロトタイプの
QA(品質確認・バグ修正)を担当するエンジニアです。

【ゲームの仕様概要】
- HTML/CSS/JS(フレームワークなし)。家画面 → てんのお世話画面 → 赤ちゃんメモ画面、の構成
- お世話画面では、赤ちゃんの内部状態(空腹・眠気・おむつ・抱っこ欲求・体感温度・不快感、いずれも0〜100)を
  プレイヤーには見せず、観察(声・表情・仕草)から手がかりを与える
- お世話(ミルク・抱っこ・寝かせる・おむつ・環境・あやす)をすると状態が変化し、
  段階的な反応演出(吹き出し→仕草→表情→結果メッセージ)が出る
- 発見システムで赤ちゃんメモに手がかりが蓄積されていく
- localStorageに保存・読込

【今回お願いしたいこと】
このファイル一式(index.html, style.css, script.js が1セット)を渡すので、
以下の観点でチェックし、**見つかったバグの修正のみ**行ってください
(仕様の変更・新機能の追加はしないでください)。
1. PC/スマートフォンそれぞれの画面幅で表示崩れがないか
2. ボタン操作後に意図しない表示(要素が残る、消えないなど)が起きないか
3. localStorageの保存・読込がリロード後も正しく機能するか
4. JavaScriptのコンソールエラーが出ないか

【出力してほしい形式】
1. 見つかった問題点の一覧(再現手順つき)
2. 修正後の該当ファイルの**完全な内容**を、Markdownコードブロックで出力
   (問題が無かったファイルは出力不要)
```
